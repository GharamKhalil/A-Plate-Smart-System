# A-Plate — Smart Digital Plate Operations

منصة عربية متعددة الصفحات للوحة الرقمية الإلكترونية، ومراقبة المركبات، وإدارة التنبيهات والمفتشين والتقارير.

## الملفات

| المسار | الوظيفة |
|---|---|
| `public/dashboard.html` + `public/pages/dashboard.js` | لوحة القيادة وخريطة المركبات والرؤى التشغيلية |
| `public/alerts.html` + `public/pages/alerts.js` | التنبيهات والإسناد والإغلاق والحذف والتوثيق |
| `public/analytics.html` + `public/pages/analytics.js` | ستة رسوم SVG وتصدير تقرير CSV |
| `public/vehicles.html` + `public/pages/vehicles.js` | لوحة رقمية **مبرمجة**، البحث بعنوان IP، الموقع وإجراءات اللوحة |
| `public/inspectors.html` + `public/pages/inspectors.js` | قائمة المفتشين والخريطة وإسناد المهام |
| `public/assets/styles.css` | أنماط مشتركة ومتجاوبة |
| `public/assets/core.js` | القائمة، اختيار المنطقة، الإشعارات، الجلسة، SSE، API |
| `public/assets/map.js` | خريطة Leaflet بشوارع حقيقية ومؤشرات متعددة، وخريطة احتياطية عند عدم تحميل المكتبة |
| `server.mjs` | خادم Node.js لحفظ البيانات والتحديث الفوري |

## التشغيل

يتطلب Node.js 20 أو أحدث. على Windows PowerShell:

```powershell
.\START-WINDOWS.ps1
```

ثم افتح `http://localhost:3000/`. التشغيل المحلي يتجاوز صفحة الدخول دون تعريض مفتاح الإدارة للمتصفح. **لا تضف أسرار التشغيل إلى GitHub**.

يمكن التشغيل يدويًا من خلال متغيرات `DEVICE_KEY` و`ADMIN_KEY` ثم `npm start`.

فحص الاختبارات:

```powershell
npm run check
npm test
```

## تزامن البيانات

- يتصل المتصفح بالخادم عبر `GET /api/events` (SSE) ويُحدّث كل الواجهات والإشعارات عندما تتغير بيانات الخادم.
- يرسل الجهاز بياناته إلى `POST /api/ingest` بترويسة `x-device-key`. مثال بيانات:

```json
{"deviceId":"AP-745310","battery":91,"speed":42,"lat":24.7136,"lng":46.6753,"tamper":false,"counter":1120,"sensor":"0.0"}
```

- حالة المركبة **لا تتغير عشوائيًا**؛ لا تُحدَّث إلا عند ورود قراءات جديدة أو عمليات المستخدم. الخريطة الأساسية خريطة شوارع من مزود خارجي وليست خدمة خرائط مرور حية. عند فشل تحميل مكتبة Leaflet تظهر خريطة جغرافية احتياطية مبسطة. موقع الجهاز لا يصبح حقيقيًا إلا إذا أرسل جهاز مرتبط إحداثيات GPS فعلية.
- عند أول تشغيل ينشأ مخزن ببيانات **توضيحية** داخل مجلد `data`. هذا المخزن خاص بالنسخة الأولية وليس سجل مرور رسميًا. يتم حفظ التغييرات محليًا في `data/state.json`؛ للمؤسسات يلزم قاعدة بيانات موثوقة، إدارة مستخدمين وصلاحيات، سجلات تدقيق، واستضافة HTTPS.
- طلبات التحكم (قفل/جرس/تعطيل/إعادة تشغيل) **تُسجل فقط** في هذه النسخة ولا تصل إلى اللوحة الفيزيائية. يتطلب تنفيذها قناة موقعة مؤمنة وتأكيدًا من الجهاز الفعلي.
- الإشعارات والرؤى تُستنتج من البيانات الموجودة. لا يوجد نموذج تنبؤ AI مدرَّب ولا اتصال رسمي بأنظمة مرور.

## الأمن والنشر

هذه نسخة تشغيلية **أولية للعرض والتطوير**، وليست نظامًا مرخصًا أو معتمدًا من جهة حكومية. لا تستخدم بيانات مواطنين حقيقية في النسخة الأولية. الواجهة لا تعرض مفتاح الإدارة؛ الوصول المحلي المباشر مقصور على الجهاز نفسه. يتطلب النشر العام TLS وقاعدة بيانات ومصادقة مؤسسية قبل إتاحة صلاحيات التعديل. لا تنشر `server.mjs` كواجهة عامة دون استكمال التحصين. GitHub Pages وحدها لا تشغّل الخادم أو المزامنة.


## تحديث الواجهات والخرائط
- كل واجهة لها HTML وJS مستقل.
- تبدأ نسخة Windows المحلية دون صفحة تسجيل الدخول (`APLATE_SKIP_LOGIN=1`)، **فقط للاتصالات من نفس الجهاز**؛ لا يفتح هذا صلاحيات الإدارة عبر الإنترنت.
- عرض الخرائط الحقيقية يعتمد على Leaflet وطبقات طرق CARTO/OSM مع اتصال إنترنت؛ إذا تعذر تحميل الخريطة يُعرض تنبيه، وتتوفر خريطة SVG احتياطية عند تعذر تحميل مكتبة Leaflet.
- أضيفت سجلات عرض أولية لمركبات ومفتشين متعددين في عدة مناطق، ولا تمثل مواقع أشخاص أو أجهزة حقيقية. بيانات الأجهزة الحقيقية تصل فقط عبر `/api/ingest`.
- تتحدث الرؤى عند وصول البيانات، ويجري تدوير الرؤى المبنية على السجلات كل 12 ثانية. لا يُنشئ العرض بيانات حركة أو بلاغات عشوائية.
- **لا تنشري وضع الوصول المحلي كخادم إدارة مكشوف على الإنترنت**. للنشر الجماعي استخدمي مصادقة آمنة وصلاحيات مفصلة.

للتشغيل على Windows عند حظر سكربت PowerShell، استخدمي الملف `RUN-A-PLATE.cmd` الذي يشغل سكربت المشروع بسياسة تنفيذ مؤقتة ضمن عمليته فقط.


## الخرائط عند تعذر اتصال مزود الخرائط

- تعرض الواجهة خريطة Leaflet الحقيقية عندما تتوفر بلاطات OpenStreetMap عبر الإنترنت.
- عند فشل تحميل البلاطات، تظهر صورة خريطة الرياض المرجعية المرفقة (مأخوذة من لقطة شاشة للمشروع) بدل الخلفية الرمادية. الصورة ثابتة؛ مواقع العلامات تقريبية على الصورة، وليست خريطة جغرافية ملاحيّة موثوقة.
- المناطق الأخرى تحتفظ بالخريطة التخطيطية كبديل.
- للحصول على شوارع دقيقة وتكبير سلس دون إنترنت، يلزم تثبيت حزمة خرائط أوفلاين مرخصة (MBTiles/PMTiles أو ملفات بلاطات محلية تغطي المنطقة بدرجات التكبير المطلوبة) وربطها بالمشروع، ولا يمكن الحصول على هذه الدقة من صورة واحدة.
